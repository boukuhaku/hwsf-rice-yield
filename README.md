# HWSF: Preharvest Municipal Rice Yield Estimation

Project page of the manuscript *Preharvest Municipal Rice Yield Estimation With Hierarchical Weather and Sea Surface Temperature Fusion and Uncertainty Quantification*.

Page: https://boukuhaku.github.io/hwsf-rice-yield/

Code and fitted models: https://github.com/boukuhaku/HWSF

The page summarizes the model (HWSF), the uncertainty evaluation, and the main results. Figures and numbers are taken from the manuscript. The source data are not redistributed here; the page lists their providers.
